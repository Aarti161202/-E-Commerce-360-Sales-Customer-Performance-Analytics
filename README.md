# E-Commerce Analytics Dashboard

## Project Overview

The **E-Commerce Analytics Dashboard** is a data analytics and visualization project developed to analyze e-commerce business performance, customer behavior, sales trends, product performance, and order-related information. The main objective of this project is to transform raw e-commerce data into meaningful business insights using data cleaning, transformation, analysis, and interactive visualization techniques.

The project analyzes important business metrics such as **Total Sales, Total Orders, Total Customers, Average Order Value (AOV), Profit, and Profit Margin**. These KPIs provide a quick overview of the overall performance of the e-commerce business. The dashboard also helps identify top-performing products and categories, understand customer purchasing patterns, and analyze changes in sales over different time periods.

## Key Analysis

The dashboard includes **daily and monthly sales trend analysis** to understand business growth and fluctuations over time. Category-wise analysis is performed to compare sales and profitability across different product categories. A **Top 10 Products** analysis helps identify products that contribute significantly to overall sales.

Customer analysis is used to understand purchasing behavior and identify repeat customers. The project also analyzes different **payment methods** to understand customer payment preferences. Order status analysis provides insights into delivered, cancelled, returned, and pending orders.

Interactive filters such as **Date, Category, Payment Method, and Order Status** allow users to explore the data according to specific business requirements. Users can select different filter combinations and dynamically analyze the corresponding results.

## Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **SQL** – Data querying and analysis
* **Excel** – Data preparation and initial analysis
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures, calculated columns, and KPI calculations

## Skills Demonstrated

This project demonstrates practical knowledge of **data cleaning, data transformation, data modeling, exploratory data analysis, DAX, KPI creation, interactive dashboard development, and business analytics**.

## Business Value

The dashboard helps businesses understand sales performance, customer behavior, product demand, category profitability, and order patterns. These insights can support better decisions related to **sales strategy, inventory management, marketing activities, product performance, and customer engagement**.

Overall, this project demonstrates how data analytics and visualization can convert raw e-commerce data into actionable business insights and support data-driven decision-making.
